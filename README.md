# CryptX-Project
CryptX project description

This a cryptX dashboard to showcase my use and understanding of Figma, i used icons and correct information to properly replicate the figma design.
CryptX is a modern, responsive cryptocurrency dashboard built with React and Tailwind CSS, developed as a replication of a Figma design.  
The project focuses on clean UI implementation, component reusability, and accurate visual alignment with the original mockup.

Key Features:
- Responsive layout for all screen sizes  
- Collapsible sidebar navigation  
- Dynamic cryptocurrency cards (Bitcoin, Ethereum, etc.)  
- Consistent, modern design inspired by Figma  

Tech Stack: React • Tailwind CSS • Lucide React Icons
